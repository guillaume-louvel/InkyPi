# Plugin InkyPi « Comptes à rebours »

Plusieurs comptes à rebours affichés en cartes noir et blanc : le nombre de jours
en grand, le nom de l'événement dessous, puis la date.

## Réglages

- **Événements** (jusqu'à 50) : un nom, une date et une répétition :
  - *Une seule fois* : une échéance ; la carte disparaît le lendemain.
  - *Chaque année* : Noël, une fête… (l'année saisie n'a pas d'importance).
  - *Anniversaire* : chaque année, avec l'âge (« 8 ans ») calculé depuis l'année saisie.
    Un 29 février tombe le 28 les années non bissextiles.
- **Nombre maximum de cartes** (1 à 8) : seuls les événements les plus proches sont
  affichés. La grille s'adapte (4 cartes : 2 × 2, 6 : 3 × 2, 8 : 4 × 2 ; transposée en portrait).
- **Titre** : facultatif, au-dessus des cartes.

Le jour J, la carte affiche « Aujourd'hui ». Un rafraîchissement par jour suffit
(par exemple programmé à 00:05).
